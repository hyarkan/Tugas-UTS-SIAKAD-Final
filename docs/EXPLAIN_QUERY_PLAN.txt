Bukti EXPLAIN QUERY PLAN - Modul KRS Minggu 5
Database: SQLite setelah alembic upgrade head dan python -m app.seed

Perintah:
EXPLAIN QUERY PLAN
SELECT m.nama
FROM prerequisite p
JOIN matakuliah m ON m.kode_mk = p.kode_prasyarat
WHERE p.kode_mk = 'IF201'
  AND NOT EXISTS (
    SELECT 1
    FROM krs_detail kd
    JOIN krs k ON k.id = kd.krs_id
    JOIN skala_nilai sn ON sn.nilai = kd.nilai
    WHERE k.nim = '20260010001'
      AND k.semester < '20261'
      AND kd.kode_mk = p.kode_prasyarat
      AND sn.lulus = 1 AND sn.bobot >= 2
  );

Kesimpulan:
SQLite menggunakan indeks untuk pencarian pada prerequisite, krs, krs_detail,
skala_nilai, dan matakuliah. Ini adalah hasil aktual pada database SQLite
lokal untuk tugas; hasil dan optimizer dapat berbeda pada MySQL/produksi.
